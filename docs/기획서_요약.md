# Super Game 기획서 요약

**작성:** 조승영 (202613111)

## 게임 개요

- **장르:** 화면 안 생존 (3분 버티기)
- **목표:** 화면을 벗어날 수 없는 구슬을 3분 동안 유지하며 쏟아지는 적을 처치

## 게임 규칙

1. **화면 제한:** 플레이어는 화면 밖으로 나갈 수 없음
2. **적 추가:** 시간이 지날수록 적이 점점 많이 등장
3. **조각 성장:** 적 처치 시 조각 드롭 → 16개마다 주변 무기(구슬) 1개 추가
4. **클리어:** 3분 생존 시 CLEAR 화면 → ENTER 로 종료
5. **패배:** 적과 플레이어 충돌 시 GAME OVER

## 구현 기술

- **원운동 무기:** Cos/Sin으로 360° 배치, 매 프레임 좌표 갱신
- **적 스폰:** 플레이어 기준 radius 밖 원주상 랜덤 각도 (Cos/Sin)
